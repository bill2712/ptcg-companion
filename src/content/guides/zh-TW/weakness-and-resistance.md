弱點是寶可夢卡牌中影響最大的傷害加成。它會令招式的傷害**加倍**，把一下普通的攻擊變成一擊擊倒。抵抗力的影響較小，但在勢均力敵的對戰中同樣可以左右勝負。這篇攻略解釋兩者，以及它們所依據的屬性。

## 十種屬性

現行寶可夢卡牌共有十種屬性，以 HP 旁邊的符號表示：

| 屬性 | 常見的寶可夢 |
| --- | --- |
| 草 | 植物和蟲類寶可夢 |
| 火 | 火屬性寶可夢 |
| 水 | 水和冰屬性寶可夢 |
| 雷 | 電屬性寶可夢 |
| 超 | 超能力、幽靈和妖精屬性寶可夢 |
| 鬥 | 格鬥、地面和岩石屬性寶可夢 |
| 惡 | 惡和毒屬性寶可夢 |
| 鋼 | 鋼屬性寶可夢 |
| 龍 | 龍屬性寶可夢 |
| 無色 | 一般和飛行屬性寶可夢 |

卡牌遊戲的屬性比電子遊戲少，所以好幾種電子遊戲屬性會合併在一起。舊卡曾經有**妖精**屬性，現已取消；現行卡牌中的妖精寶可夢通常是超屬性。

**基本能量**只有其中八種屬性，沒有基本龍能量或無色能量：龍屬性寶可夢通常需要兩種不同屬性的能量，而無色的能量需求則可以用任何能量支付。

## 弱點：×2

弱點印在卡的左下方，以一個屬性符號和 **×2** 表示。當該屬性的寶可夢對身處**戰鬥場**的這隻寶可夢造成傷害時，傷害會加倍。

例子：你的雷屬性寶可夢以 110 傷害的招式攻擊一隻弱點為雷的水屬性寶可夢，招式會造成 **220** 傷害，足以一擊擊倒大部分寶可夢 ex。

## 抵抗力：−30

抵抗力印在弱點旁邊，以一個屬性符號和 **−30** 表示。來自該屬性的傷害會減少 30。很多現行卡牌沒有抵抗力，所以比弱點少見。

例子：60 傷害的招式攻擊一隻對該屬性有抵抗力的寶可夢，只會造成 **30** 傷害。

## 不適用的情況

- **備戰寶可夢**：除非招式另有說明，對備戰區造成的傷害不計算弱點和抵抗力。
- **傷害指示物**：「放置傷害指示物」而非「造成傷害」的效果，完全不計算弱點和抵抗力。
- **寶可夢檢查**：中毒和灼傷的傷害不是招式，所以兩者都不適用。
- **看寶可夢的屬性，不是能量**：弱點取決於**攻擊方寶可夢的屬性**，與身上附加的能量屬性無關。

## 次序很重要

弱點和抵抗力在攻擊方的效果之後、防守方的效果之前計算：

1. 基本傷害和招式說明
2. 攻擊方的效果（+）
3. **弱點（×2）**
4. **抵抗力（−30）**
5. 防守方的效果（−）

計算例子請參考[傷害計算方法](/zh-TW/guides/damage-calculation/)，也可以用[傷害計算器](/zh-TW/tools/damage-calculator/)自動計算。

## 常見的屬性相剋

每張卡的弱點都可能不同，所以一定要看清楚眼前的卡。不過，很多近期的卡都依循以下常見模式：

| 屬性 | 常見弱點 |
| --- | --- |
| 草 | 火 |
| 火 | 水 |
| 水 | 雷或草 |
| 雷 | 鬥 |
| 超 | 惡或鋼 |
| 鬥 | 草或超 |
| 惡 | 草或鬥 |
| 鋼 | 火 |
| 無色 | 鬥 |
| 龍 | 通常沒有弱點 |

這個表格只是用來預判可能的威脅，並非固定規則。

## 實戰運用

### 組牌時

- 留意你身邊最流行的牌組。如果當中很多都有相同的弱點，該屬性的寶可夢即使只放一張，也可以是很好的**針對卡**。
- 檢查自己主攻手的弱點。如果某個流行牌組可以對它造成雙倍傷害，可以考慮加入另一種屬性的後備攻擊手。
- 能以無色能量使用招式的寶可夢，幾乎可以放進任何牌組，所以經常被用作針對卡。

### 對戰時

- 使用招式前，先看看防守方寶可夢的弱點。用交換或「拉人」效果，把弱點是你屬性的備戰寶可夢拉到戰鬥場，可以把兩擊擊倒變成一擊。
- 選擇戰鬥寶可夢時，如果可以選擇，盡量避免讓弱點是對手主攻手屬性的寶可夢出場。
- 計算獎賞卡時別忘記弱點：一記雙倍傷害擊倒寶可夢 ex，就值 2 張獎賞卡。
